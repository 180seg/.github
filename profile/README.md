# 180 Seguros

Somos uma seguradora que nasceu para redefinir a forma de fazer seguros.


Criamos soluções que se integram às jornadas dos nossos parceiros, permitindo que eles ofereçam proteção aos seus clientes do jeito certo e no momento certo.


Cuidamos de toda a operação, de ponta a ponta, eliminando a complexidade. 


É assim que tornamos o seguro a parte mais simples do processo, para que o foco esteja no que realmente importa.
